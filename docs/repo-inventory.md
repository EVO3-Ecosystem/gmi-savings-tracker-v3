# Repository inventory

Complete inventory of `EVO3-Ecosystem/gmi-savings-tracker-v3`, every folder, subfolder and document, numbered. As of `main@c0f7484` (November 19, 2026): **620 files in 46 directories** (plus the repository root). Companion to [`refresh-plan.md`](refresh-plan.md), which turns this inventory into the global refresh checklist and the downstream asset log for the Pages site and external consumers.

Every entry carries one provenance tag saying **what writes or maintains it**, and the refresh columns say whether it changes on a **Total refresh** (full pipeline run: `make extract && make build && make export && make site-snapshot`, then figures/docs) or a **Pages update** (push to `main` → the Pages workflow rebuilds the site from `site_data/`).

| Tag | Meaning |
|---|---|
| `hand` | Written and maintained by hand. Changes only when a person edits it. |
| `run:export` | Regenerated by `make export` and committed to `site_data/` by `make site-snapshot`. |
| `run:facts` | Regenerated by `python -m src.models.doc_facts` (runs inside the Extract-and-build workflow) — README fact block and the `facts:` blocks in `docs/models/`. |
| `run:figures` | Regenerated by `make figures`, `make overview-figures`, `make readme-shots` or `make diagrams`. |
| `run:gov` | Regenerated by `make docs` (`src.pipeline.governance`): `docs/schemas/*` and the generated sections of `docs/data-governance.md`. |
| `run:recon` | Regenerated by `make reconcile` / `parity_published` (`docs/reconciliation/`). |
| `run:parity` | Regenerated by `make parity` (`docs/parity/`). |
| `run:nb` | Regenerated by `make notebook` (`scripts/build_walkthrough.py` + `scripts/render_notebook.py`). |
| `lock` | Regenerated by `make lock` (`uv lock` + `uv export`). |
| `legacy` | Frozen v1/Spend Lens artifact. Never regenerated; kept for parity and history. |
| `ci` | Workflow automation; runs in GitHub Actions. |


Pipeline outputs that are **not committed** (`.gitignore`d) and therefore not numbered below: `data/` (raw Parquet runs, `md_transparency.duckdb`, `runs.csv`, `check_history.csv`, `export/`), `site/` (the built dashboard the Pages workflow deploys), `hf_stage/`. They are regenerated on every total refresh; see refresh-plan §2.
